# Prepare an FDX handoff

1. Export your current screenplay as FDX and a matching PDF. Keep both versions
   together so collaborators can compare structure with the intended layout.
2. Inspect the FDX. Read warnings first; then review production signals such as
   revision marks, omitted scenes and locked pages.
3. Open the file in the receiving application. Compare the first and last scene,
   scene numbers, dual dialogue and any marked revisions against the PDF.
4. Record the application versions and any differences you need to resolve.

The inspector gives you a checklist drawn from the actual file. It does not
replace the comparison in step 3: page layout depends on the receiving application.

For a reusable delivery checklist, see the
[Writing Handbook](https://github.com/inkwell-app/writing-handbook/tree/main/workflows).
To continue the draft in Inkwell, follow the
[FDX import guide](https://www.inkwell.software/resources/guides/import-fdx?utm_source=github&utm_medium=referral&utm_campaign=fdx_inspect&utm_id=github_fdx_inspect&utm_source_platform=github&utm_content=handoff_import).
